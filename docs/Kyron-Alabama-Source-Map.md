Research complete. Evidence-backed findings below (all URLs were actually opened or fetched during this session):

## 1. Mobile County — YES, it has its own separate portal (MCHD)

Mobile County is **not** primarily served through the ADPH site. The Mobile County Health Department (MCHD) — one of Alabama's two independent county health departments — publishes its own ratings:

- **Portal:** https://mchd.org/restaurant-ratings-mobile/ (opened and verified). Page title: "Restaurant Ratings - Mobile - Mobile County Health Department," with the instruction "Tap an establishment for ratings and details."
- **How it works:** A single searchable/sortable table (a WordPress wpDataTables widget fed from a database — verified in the page source). Per the table's own column definitions in the page code, there are exactly **7 columns**: Establishment, Address, City/State/Zip, Latest Inspection, and three Previous Inspection columns (fields `EST_NAME`, `EST_ADDRESS`, …, `INS_ONE`–`INS_FOUR`). A search box filters by text; tapping a row shows its ratings/details.
- **Violation details: NO.** The word "violation" (and "critical") appears **zero times** in the page source, and there is no violation column in the table schema. MCHD publishes **scores/history only** — the latest inspection plus up to three previous ones. (Rows load via AJAX, so I verified the schema from the raw page source rather than rendered rows; the local outlet Mobile Bay Now's republication of MCHD's September 2026 scores — https://mobilebaynow.com/mobile-county-health-inspection-scores-for-september-2026-see-how-your-favorite-spot-did/ — likewise lists only name, address, and score, consistent with a scores-only feed.) Per MCHD's own site (search result from https://mchd.org/), MCHD also pushes scores through its free "My MCHD Health Check" smartphone app.
- Practical note for Kyron: Mobile is a **third ingestion source** (JCDH-style), scores + history but no "why" data — same tier as ADPH, not JCDH.

## 2. ADPH — foodscores.state.al.us (opened and exercised live)

**(a) County dropdown:** I fetched the live search form's raw HTML twice today (https://foodscores.state.al.us/default.aspx). The county dropdown has **68 options: "Select County" + all 67 Alabama counties — JEFFERSON (value 37) and MOBILE (value 49) ARE both listed.** Nothing is excluded from the dropdown.
- Caveat, honestly flagged: I could **not** verify whether a JEFFERSON or MOBILE search actually returns records. After one fully successful search (below), four follow-up attempts for Jefferson/Mobile failed at the connection level (one pair returned HTTP 302 session redirects; later attempts dropped before any response — the same flakiness seen in earlier ADPH work). Given that ADPH's own organizational description calls Jefferson and Mobile "the two independent city-county health departments" and both run their own portals (above), live ADPH coverage is most plausibly the other 65 counties — but treat "dropdown lists them" as verified and "returns data for them" as **unverified**.

**(b) Search results format — verified with a live query** (name "SUBWAY" + Winston County; the page reported "Results for County: WINSTON," "Total Number: 2"). Results render as a DataList (`DtList`, class `datagridView`), sortable via header links (SortBy=EstablishmentName/City/ZipCode/Score/SmokingPreference/InspectionDate). Each establishment shows **only**:
- Establishment Name, Address, City, Zip Code, **Score**, Smoke Free (Yes/No), **Inspection date** — plus a Google Maps link for the address.
- Example rows returned: "SUBWAY, 1300 11TH AVE, HALEYVILLE, 35565, Score 97, Smoke Free Yes, 6/16/2026" and "Subway Double Springs, 26285 Hwy 195, Double Springs, 35553, Score 98, 8/28/2026."
- **There is NO per-establishment detail page or link and NO violation data anywhere in the results** — the only links are the sort headers and Google Maps. ADPH online = latest score + date, nothing more. (Violation detail exists only on the paper inspection report posted in the establishment; the ADPH intro page I opened says critical violations are "identified in red on the inspection report" — i.e., the physical report.)
- Bonus finding for the fix work: Kyron 1.0's AdphScraper parses `table#gvSearchResults` — **no element with that ID exists** in today's live results markup (results are in `#ctl00_ContentPlaceHolder1_DtList`), so the current app's ADPH parsing is mismatched with the live site independent of the site's slowness.
- Form structure (for the record): ASP.NET postback with `__VIEWSTATE`/`__EVENTVALIDATION`, cookieless session URL `/(S(...))/default.aspx`; fields Establishment Name (text), Establishment Type (dropdown: All, Camp, Catering, Daycare, Food Service Establishment, Retail Food Store, School Lunchroom, etc.), City (text), County (dropdown above).

## 3. Other separate Alabama portals — none found besides Jefferson + Mobile

- Alabama has exactly **two** independent county health departments. ADPH's own description (quoted on the ADPH Wikipedia page, https://en.wikipedia.org/wiki/Alabama_Department_of_Public_Health, and in ADPH's LinkedIn profile): ADPH supports county health departments in all counties plus "the two independent city-county health departments in Jefferson County, Alabama and Mobile County, Alabama," which are governed by their local boards of health.
- Therefore the complete Alabama source map is **three sources**: **JCDH** (Jefferson — scores + full violations + history), **MCHD** (Mobile — scores + history, no violations), **ADPH** (the other 65 counties — latest score + date only).
- Montgomery County is **not** a separate portal: it sits in the ADPH dropdown (verified in the live form), and the old third-party listing (Food Poison Journal) points Montgomery to an adph.org county page. The dead Montgomery ArcGIS service from the earlier audit was a City of Montgomery GIS layer, not a health-department portal — no replacement exists or is needed for coverage, since ADPH covers Montgomery County.

**Bottom line for the "complete Alabama" milestone:** three server-side ingesters (JCDH, MCHD, ADPH-with-corrected-parser), with the caveat that "why" summaries are only possible in Jefferson County — ADPH and MCHD publish no violation data online at all.
